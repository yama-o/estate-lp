# CMPS不動産 原状回復サービスLP

不動産原状回復・業務サポートサービス「CMPS不動産（もとのくらし）」のランディングページ（LP）です。
管理会社様・オーナー様・入居者様の悩みを解決するサービスを、信頼感のあるモダンなデザインで紹介しています。

## 🌐 公開URL
https://yama-o.github.io/cmps-lp/

## 🛠 特徴
* **レスポンシブデザイン**: スマートフォン、タブレット、PCに完全対応
* **スタイリッシュなUI**: 高級感のあるネイビー×ゴールドの配色と、余白を活かしたレイアウト
* **アニメーション**: スクロールに合わせて要素がフワッと浮き上がるフェードイン効果
* **軽量設計**: 外部フレームワークを使わず、HTML/CSSのみで構築（高速読み込み）

## 📂 ファイル構成
* `index.html`: サイトのメインソースコード
* `konusi.png`: ファーストビュー（トップ）のメイン画像

## 🚀 編集・運用の仕方

### 画像を変更する場合
1. 使いたい画像をリポジトリにアップロードする。
2. `index.html` 内の `<img>` タグの `src` を新しいファイル名に書き換える。

### テキストを変更する場合
1. `index.html` を開き、該当する箇所のテキストを編集する。
2. 変更をCommit（保存）すると、自動的にサイトに反映されます。
